Instalar

Instalação completa, passo a passo.

Pensado para quem não é técnico: copie, cole e responda algumas perguntas.

Pré-requisitos

VPS Ubuntu 24.04 (root) Domínio na Cloudflare Cloudflare Zero Trust
1 comando · instala tudo
$ bash <(curl -fsSL https://raw.githubusercontent.com/giovani-junior-dev/megaAPI-Chatwoot/master/install-pack/bootstrap.sh)
  1. 1Crie o Tunnel no CloudflareZero Trust → Networks → Tunnels → Create. Copie o token (começa com eyJ...).
  2. 2Rode o instaladorResponda: hostnames (chatwoot, bridge, portainer, backup), token do tunnel e senhas. O resto é gerado automaticamente.
  3. 3Crie os endereços públicosNo tunnel, adicione 4 Public Hostnames (tipo HTTP) apontando para os serviços. Use subdomínio de 1 nível.
  4. 4Configure o ChatwootCrie a conta admin e a caixa de entrada do tipo API.
  5. 5Crie o tenant no painelInforme os dados do WhatsApp e da caixa de entrada. O webhook é configurado sozinho.
  6. 6Pareie e testeGere o link de pareamento, escaneie o QR e envie a primeira mensagem.
Dica: use subdomínios de 1 nível (ex.: chatwoot.seudominio.com). E crie a caixa de entrada no Chatwoot antes de criar o tenant.
Dúvidas

Perguntas frequentes.

Preciso ser técnico para instalar?

Não. A instalação é um comando só; o instalador pergunta o essencial (domínio, token e senhas) e configura todo o resto sozinho.

Onde fica hospedado?

Tudo roda na sua própria VPS, autohospedado. Você é dono dos dados e das conversas.

Preciso abrir portas no servidor?

Não. O acesso é feito pelo Cloudflare Tunnel, com HTTPS automático e sem expor as portas 80/443.

Funciona com vários clientes?

Sim. É multi-tenant: cada cliente tem sua instância de WhatsApp ligada a uma caixa de entrada do Chatwoot.

Envia arquivos, não só texto?

Sim, mensagens nos dois sentidos com suporte a texto e mídia.
