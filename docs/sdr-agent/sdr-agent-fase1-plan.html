Purpose

Plano de implementação da Fase 1 do SDR Agent: atender inbound WhatsApp ponta-a-ponta via Chatwoot AgentBot (resolve rotina + qualifica lead + escala com contexto + fecha + resume). Single-tenant instance-per-company. NestJS + Claude Agent SDK (TS). Lente code-craftsman: flat, YAGNI, TDD-first, sem WhatsApp no agente.

Problem

Giovani atende sozinho, não escala. Cada minuto no Chatwoot é minuto fora do negócio. Precisa de atendimento automático de qualidade que escale pra humano só quando faltar contexto.

Solution

AgentBot no inbox WhatsApp. Msg do cliente → webhook → NestJS monta contexto (AGENT.md + KB + memória ai-memory + histórico) → loop Claude Agent SDK com tools Chatwoot → responde / escala / fecha. Entrega sai pela camada Chatwoot (bridge→megaAPI). Agente nunca toca WhatsApp → troca de core (megaAPI↔oficial) é embaixo dele, sem reescrita.

Requisitos (EARS)

IDPadrãoRequisito
REQ-1eventWhen msg do cliente chega (message_created, incoming, não-privado) no outgoing_url, the agente shall montar contexto e gerar resposta ou escalação na conversa.
REQ-2unwantedIf o evento é mensagem outgoing/do próprio bot, then the receiver shall descartar (anti-loop).
REQ-3unwantedIf message.id já processado, then the receiver shall descartar duplicata (idempotência).
REQ-4stateWhile uma conversa está em processamento, the orchestrator shall serializar novas msgs dessa conversa (sem resposta dupla).
REQ-5eventWhen falta contexto KB / tema sensível / pedido humano / lead quente / N turnos, the agente shall escalar (status open + assign + label + nota com motivo).
REQ-6eventWhen o agente resolve, the agente shall fechar (status resolved) e gravar resumo+gaps no ai-memory.
REQ-7unwantedIf o agente erra/timeout/rate-limit, then the system shall escalar pra humano com nota "falha técnica" (fail-safe, sem silêncio).
REQ-8ubiquitousThe system shall nunca enviar WhatsApp direto; entrega só via mensagem outgoing no Chatwoot.
REQ-9stateWhile atende um contato, the agente shall carregar e atualizar a página de memória do contato no ai-memory.

Arquitetura

src/
  config/        # loader + schema (company config, AGENT.md path, creds)
  webhook/       # controller outgoing_url: filtro + anti-loop + dedupe + enqueue
  orchestrator/  # monta contexto, roda agente, serializa por conversa
  agent/         # Claude Agent SDK setup + tools + system-prompt(AGENT.md)
  chatwoot/      # client REST (única superfície HTTP→Chatwoot)
  kb/            # loader markdown + consultar_kb (busca textual, sem vetor)
  memory/        # wrapper ai-memory MCP
  summarizer/    # resumo + gaps ao resolver
config/<empresa>/
  AGENT.md       # personalidade+playbook (estilo CLAUDE.md)
  kb/*.md        # contexto curado
test/

Regras de fronteira:

#Regra
1Módulos não importam internals de outro módulo (SRP por pasta).
2chatwoot/ é a ÚNICA superfície HTTP→Chatwoot. Tools chamam o client, não fetch cru.
3Zero código WhatsApp/megaAPI/wablast em qualquer lugar (D10).
4Sem interface sem 2ª impl. 1 Chatwoot client concreto, sem IChatwoot.
5Sem UseCase/Port/Adapter/Mapper. Flat: input→lógica→efeito.
